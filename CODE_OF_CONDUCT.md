# Community code of conduct

Be respectful, constructive, and specific. Welcome people with different
backgrounds and levels of experience. Critique ideas and code without personal
attacks. Harassment, threats, discriminatory abuse, doxxing, and disclosure of
private credentials or personal information are not acceptable.

Maintainers may edit or remove inappropriate content, close disruptive threads,
or restrict participation. Reports should be handled with discretion and fairness.
Use a minimal, factual issue for ordinary moderation concerns; for sensitive
reports, contact the repository owner through a private channel listed on their
GitHub profile. Do not publish private details in an issue.

These expectations apply to repository issues, pull requests, discussions, and
other community spaces associated with this project.

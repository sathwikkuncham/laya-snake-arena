# Changelog

## 0.1.0 — 2026-09-21

- Windows Snake adaptation using a resident ggmlc Laya process.
- Optional live TypeSafe JEV comparisons with matched starting configuration.
- Full-speed and paced solo play, typed probabilities, visible safety overrides,
  request timing, and JSON game exports.
- Configurable board, prompt style, move limits, recording retention, and engine list.
- Provider registry with validated responses and a labeled non-AI plugin example.
- Dynamic comparison UI for one to four configured engines.
- Portable launcher, environment configuration, offline tests, and Windows/Linux CI.
- Setup, extension, contribution, security, and recording documentation.
- Real-time solo and comparison MP4s distributed as release assets.
